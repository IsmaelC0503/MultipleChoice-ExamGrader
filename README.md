# Calificador de Exámenes de Opción Múltiple

Sistema automático de calificación de exámenes de opción múltiple usando la 
Transformada de Hough para detectar los círculos de respuesta y conteo de 
píxeles (momentos) para identificar la opción marcada.

## 📋 Descripción del Proyecto

Este proyecto desarrolla un sistema automático de calificación de exámenes de 
opción múltiple mediante técnicas de visión por computadora. El sistema detecta 
las burbujas de respuesta en la hoja de examen usando la Transformada de Hough 
y determina cuál opción fue marcada mediante operaciones de conteo de píxeles 
(momentos).

### Características principales
- Corrección de perspectiva usando marcadores en las esquinas
- Detección de burbujas mediante Transformada de Hough
- Identificación de respuestas marcadas usando conteo de píxeles (momentos)
- Calificación automática
